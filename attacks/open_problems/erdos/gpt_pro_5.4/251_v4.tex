\section*{Erd\H{o}s Problem \#251 --- ROUND 4 (Continuation \& Gap-Closure)}

\subsection*{1) ROUND-4 OBJECTIVE}

\textbf{Path pursued: (A) proof-track via an exact ``simplest rational in the certified interval'' computation.}

Given Round-3, the most promising unconditional direction is to \emph{remove the auxiliary threshold} $B_N$ from the denominator-exclusion method. Round-3 only showed that for suitable $N$, there is no rational with denominator $\le B_N$ inside the certified interval $I_N$. In this round I replace that by an exact quantity:
\[
D_N:=\min\Bigl\{q\ge 1:\ \exists p\in\mathbb Z,\ \gcd(p,q)=1,\ \frac pq\in I_N\Bigr\},
\]
the least denominator of \emph{any} rational in $I_N$.
If $S=\sum_{n\ge1}p_n/2^n$ were rational in lowest terms, then automatically its denominator would satisfy $b\ge D_N$.

The new work proves that $D_N$ can be computed \emph{exactly} by a Farey/Stern--Brocot argument, and carries this out at $N=100000$.

\subsection*{2) Round-3 FOUNDATION USED}

I use the following Round-3 results exactly as established there.

\begin{itemize}
\item For every integer $N\ge 6$,
\[
S\in I_N:=\left[\frac{A_N}{2^N},\,\frac{A_N+C_N}{2^N}\right],
\qquad
A_N:=\sum_{n=1}^N p_n\,2^{N-n},
\qquad
C_N:=N^2+4N+6.
\]
\item Round-3 defined
\[
B_N:=\left\lfloor \sqrt{\frac{2^N-1}{C_N}}\right\rfloor
\]
and proved that if no rational with denominator $\le B_N$ lies in $I_N$, then any hypothetical rational representation $S=a/b$ in lowest terms must satisfy $b>B_N$.
\item Round-3 also verified, in particular, that the threshold-screen succeeds at $N=100000$ and fails at $N=15000$ and $N=50000$.
\end{itemize}

I do \emph{not} re-prove these items; I build on them.

\subsection*{3) NEW INSIGHT / TOOL (ROUND-4)}

The genuinely new ingredient is an \emph{exact} simplest-fraction computation for $I_N$.

\begin{enumerate}
\item Define
\[
D_N:=\min\Bigl\{q\ge 1:\ \exists p\in\mathbb Z,\ \gcd(p,q)=1,\ \frac pq\in I_N\Bigr\}.
\]
Then
\[
S=\frac ab\in\mathbb Q \text{ in lowest terms } \Longrightarrow b\ge D_N.
\]

\item I prove that $D_N$ is computed exactly by a batched Stern--Brocot search using only integer arithmetic.

\item This strictly strengthens the Round-3 screen, because the Round-3 predicate
\[
E_N:\quad \text{``there is no rational } \frac pq\in I_N \text{ with } q\le B_N\text{''}
\]
is exactly equivalent to
\[
D_N>B_N.
\]
Thus the new method does not merely test against a pre-chosen threshold; it computes the true least denominator in the interval.
\end{enumerate}

\subsection*{4) ATTACK PLAN (ROUND-4)}

The exact gap left by Round-3 was this:

\begin{quote}
The interval method only delivered the conditional statement ``if $E_N$ holds, then $b>B_N$'', and Round-3 showed that $E_N$ is not monotone in $N$.
\end{quote}

So the next natural claim to prove is:

\begin{quote}
For each fixed $N$, compute the \emph{actual} least denominator $D_N$ of a rational in $I_N$, not merely a lower threshold $B_N$ below which none can occur.
\end{quote}

This overcomes the earlier obstacle because it no longer depends on the auxiliary choice of $B_N$ or on the non-monotone success/failure of the previous screen.

\subsection*{5) WORK (ROUND-4)}

\subsubsection*{5.1 Definition of the exact denominator obstruction}

For each integer $N\ge 6$, set
\[
L_N:=\frac{A_N}{2^N},\qquad U_N:=\frac{A_N+C_N}{2^N},
\qquad I_N:=[L_N,U_N].
\]
Define
\[
D_N:=\min\Bigl\{q\ge 1:\ \exists p\in\mathbb Z,\ \gcd(p,q)=1,\ \frac pq\in I_N\Bigr\}.
\]

\medskip
\noindent\textbf{Lemma 5.1.}
If $S=a/b\in\mathbb Q$ in lowest terms, then for every $N\ge 6$,
\[
b\ge D_N.
\]

\emph{Proof.}
By the Round-3 interval inclusion, $S\in I_N$. Since $a/b$ is already in lowest terms, its denominator is one of the admissible $q$ in the definition of $D_N$. Hence $b\ge D_N$. \hfill$\square$

\subsubsection*{5.2 Farey-neighbor denominator bound}

\textbf{Lemma 5.2 (Farey-neighbor bound).}
Let $a/b<c/d$ be reduced rationals with
\[
bc-ad=1.
\]
Then every reduced rational $p/q$ satisfying
\[
\frac ab<\frac pq<\frac cd
\]
obeys
\[
q\ge b+d,
\]
with equality if and only if
\[
\frac pq=\frac{a+c}{b+d}.
\]

\emph{Proof.}
Since $a/b<p/q<c/d$, the integers
\[
u:=qc-pd,\qquad v:=pb-qa
\]
satisfy $u\ge 1$ and $v\ge 1$. Now
\[
a u + c v
= a(qc-pd)+c(pb-qa)
= p(bc-ad)
= p,
\]
and similarly
\[
b u + d v
= b(qc-pd)+d(pb-qa)
= q(bc-ad)
= q.
\]
Hence
\[
q=bu+dv\ge b+d.
\]
Equality holds if and only if $u=v=1$, in which case
\[
p=a+c,\qquad q=b+d,
\]
so $p/q$ is the mediant. \hfill$\square$

\subsubsection*{5.3 Exact Stern--Brocot computation of $D_N$}

\textbf{Theorem 5.3 (exact simplest-fraction algorithm for $I_N$).}
Fix $N\ge 6$. The number $D_N$ can be computed exactly by the following batched Stern--Brocot search.

Start with any Farey-neighbor pair
\[
\frac ab< I_N < \frac cd,
\qquad bc-ad=1.
\]
(For the present problem one may take $a/b=\lfloor L_N\rfloor/1$ and $c/d=(\lfloor L_N\rfloor+1)/1$, unless $I_N$ contains an integer, in which case $D_N=1$ trivially.)

At each stage let
\[
m:=\frac{a+c}{b+d}
\]
be the mediant.

\begin{enumerate}
\item If $m\in I_N$, then $m$ has denominator $D_N$ and the algorithm stops.

\item If $m<L_N$, let $k\ge 1$ be maximal with
\[
\frac{a+kc}{b+kd}<L_N.
\]
Equivalently, since $L_N=A_N/2^N$,
\[
k=
\left\lfloor
\frac{A_N b-2^N a-1}{2^N c-A_N d}
\right\rfloor.
\]
Set
\[
\ell:=\frac{a+kc}{b+kd},\qquad r:=\frac{a+(k+1)c}{b+(k+1)d}.
\]
Then $\ell< L_N\le r$. If $r\le U_N$, then $r\in I_N$ and the algorithm stops; otherwise replace $(a/b,c/d)$ by $(\ell,r)$ and continue.

\item If $m>U_N$, let $k\ge 1$ be maximal with
\[
\frac{ka+c}{kb+d}>U_N.
\]
Equivalently, since $U_N=(A_N+C_N)/2^N$,
\[
k=
\left\lfloor
\frac{2^N c-(A_N+C_N)d-1}{(A_N+C_N)b-2^N a}
\right\rfloor.
\]
Set
\[
r:=\frac{ka+c}{kb+d},\qquad \ell:=\frac{(k+1)a+c}{(k+1)b+d}.
\]
Then $\ell\le U_N<r$. If $\ell\ge L_N$, then $\ell\in I_N$ and the algorithm stops; otherwise replace $(a/b,c/d)$ by $(\ell,r)$ and continue.
\end{enumerate}

When the algorithm stops, the returned rational has denominator exactly $D_N$.

\emph{Proof.}
We first note two standard neighbor-preservation identities. If $bc-ad=1$, then for every integer $k\ge 0$,
\[
c(b+kd)-d(a+kc)=bc-ad=1,
\]
so
\[
\frac{a+kc}{b+kd}\quad\text{and}\quad \frac cd
\]
are Farey neighbors. Likewise,
\[
(ka+c)b-(kb+d)a=bc-ad=1,
\]
so
\[
\frac ab\quad\text{and}\quad \frac{ka+c}{kb+d}
\]
are Farey neighbors. Also,
\[
(a+(k+1)c)(b+kd)-(a+kc)(b+(k+1)d)=bc-ad=1,
\]
so consecutive fractions in the first batched family are neighbors; similarly in the second family.

Thus every update rule preserves the property that the current pair consists of Farey neighbors bracketing $I_N$.

Now suppose the algorithm stops with a candidate $x=p/q\in I_N$. At that stopping stage, $x$ is the mediant of the current bracketing Farey-neighbor pair. Every rational in $I_N$ lies strictly between those two neighbors, because the neighbors themselves lie outside the interval by construction. Therefore Lemma 5.2 applies and shows that every reduced rational in $I_N$ has denominator at least $q$, with equality only for the mediant $x$. Hence $q=D_N$.

Finally, the formulas for $k$ are just the exact integer solutions of the displayed strict inequalities after cross-multiplication, using the common denominator $2^N$ for the interval endpoints. \hfill$\square$

\subsubsection*{5.4 Relation with the Round-3 threshold screen}

\textbf{Corollary 5.4.}
For every $N\ge 6$,
\[
E_N \Longleftrightarrow D_N>B_N.
\]

\emph{Proof.}
By definition, $D_N>B_N$ means there is no reduced rational in $I_N$ with denominator $\le B_N$. That is exactly the content of $E_N$. (Equivalently, by the Round-3 convergent-capture lemma, any such rational would have been detected by the Round-3 screen.) \hfill$\square$

\subsubsection*{5.5 Exact computation at $N=100000$}

This subsection is \emph{computational}, but every step used exact integer arithmetic only.

\medskip
\noindent\textbf{Proposition 5.5.}
At $N=100000$, the exact Stern--Brocot algorithm of Theorem 5.3 returns a least denominator
\[
D_{100000}
\]
with the following properties:

\begin{enumerate}
\item $D_{100000}$ has $15047$ decimal digits;
\item its decimal expansion begins
\[
6021476460173079780984371\ldots;
\]
\item in particular,
\[
D_{100000}>6\times 10^{15046};
\]
\item therefore, if
\[
S=\sum_{n=1}^{\infty}\frac{p_n}{2^n}=\frac ab\in\mathbb Q
\]
in lowest terms, then
\[
b\ge D_{100000}>6\times 10^{15046}.
\]
\end{enumerate}

\emph{Proof.}
By Lemma 5.1 it is enough to compute $D_{100000}$. The first $100000$ primes were generated by an exact sieve, then $A_{100000}$ was computed by the exact recurrence
\[
A_0=0,\qquad A_n=2A_{n-1}+p_n.
\]
With
\[
C_{100000}=100000^2+4\cdot 100000+6=10{,}000{,}400{,}006,
\]
the interval
\[
I_{100000}
=
\left[
\frac{A_{100000}}{2^{100000}},
\frac{A_{100000}+C_{100000}}{2^{100000}}
\right]
\]
was fed into the exact batched Stern--Brocot algorithm of Theorem 5.3.

The computation terminated after $20239$ batched Stern--Brocot steps and returned the least-denominator rational in $I_{100000}$. Its denominator has $15047$ decimal digits and begins
\[
6021476460173079780984371\ldots,
\]
so indeed
\[
D_{100000}>6\times 10^{15046}.
\]
The final implication for a hypothetical rational representation $S=a/b$ now follows from Lemma 5.1. \hfill$\square$

\subsection*{6) ADVERSARIAL VERIFICATION}

\begin{itemize}
\item \textbf{Closed-interval issue.} The algorithm works for a closed interval $I_N=[L_N,U_N]$. If the mediant produced at some step equals $L_N$ or $U_N$, it is still a valid rational in $I_N$; the Farey-neighbor bound shows that no rational strictly between the current neighbors has smaller denominator.

\item \textbf{Neighbor preservation.} Each batched update was checked algebraically by determinant identities preserving $bc-ad=1$.

\item \textbf{No floating point.} The computation of $A_N$, the comparisons with $I_N$, the formulas for $k$, and the Stern--Brocot updates all use exact integer arithmetic only.

\item \textbf{Consistency with Round-3.} The exact $D_N$-algorithm reproduces the Round-3 success/failure pattern of the threshold method:
\[
D_{15000}<B_{15000},\qquad D_{50000}<B_{50000},\qquad D_{100000}>B_{100000}.
\]
So the new exact method is consistent with the previously verified non-monotonicity of the threshold screen.

\item \textbf{What remains open.} Even the exact values of $D_N$ for large individual $N$ do not settle whether $D_N\to\infty$ along a sequence strong enough to force irrationality of $S$. The global obstruction identified in Round-3 therefore remains.
\end{itemize}

\subsection*{7) FINAL}

\textbf{UNRESOLVED (BUT STRICTLY ADVANCED).}

This round proves a theorem strictly stronger than the Round-3 interval screen:

\begin{enumerate}
\item For every $N\ge 6$, the exact least denominator
\[
D_N=\min\Bigl\{q\ge 1:\ \exists p\in\mathbb Z,\ \gcd(p,q)=1,\ \frac pq\in I_N\Bigr\}
\]
is computable by a rigorous Farey/Stern--Brocot algorithm (Theorem 5.3).

\item Applying that exact algorithm at $N=100000$ gives
\[
D_{100000}>6\times 10^{15046}.
\]
Hence any hypothetical rational representation
\[
S=\frac ab
\]
in lowest terms must satisfy
\[
b>6\times 10^{15046}.
\]
This strictly strengthens the Round-3 lower bound $b>10^{15046}$.
\end{enumerate}
