\section*{Erd\H{o}s Problem \#145}

\subsection*{1) ROUND-2 OBJECTIVE}

\textbf{Path C (obstruction / exact reformulation).} Round-1 already proved the cases $\alpha=0$ and
$\alpha=1$. The full statement for all $\alpha\ge 0$ is still open. In this round I do not try to restart the
whole problem. Instead, I prove that the \emph{exact frequency of every fixed gap length} exists, then I
show that all moment questions reduce to a pure tail / uniform-integrability issue for this gap
distribution. As a by-product I obtain a new unconditional proof that the limit exists for every
$0\le \alpha<1$, and I identify the limiting constant for every $0\le \alpha<3.75$ in terms of the exact gap
distribution.

\subsection*{2) Round-1 FOUNDATION USED}

I use two Round-1 facts as black boxes.

\begin{enumerate}
\item The squarefree counting function satisfies
\[
\frac{1}{x}\#\{n\le x:\mu^2(n)=1\}\to \frac{6}{\pi^2}.
\]
Equivalently,
\[
M_0(x):=\frac1x\sum_{s_n\le x}(s_{n+1}-s_n)^0 \to \frac{6}{\pi^2}.
\]
\item The first moment telescopes:
\[
M_1(x):=\frac1x\sum_{s_n\le x}(s_{n+1}-s_n)\to 1.
\]
\end{enumerate}

\subsection*{3) NEW INSIGHT / TOOL (ROUND-2)}

There are three new tools in this round.

\begin{enumerate}
\item The \textbf{exact gap frequencies} exist: for each fixed $m\ge 1$, the asymptotic density of
squarefree numbers whose next squarefree is exactly $m$ steps away exists.
\item A \textbf{moment-transfer lemma}: if some higher moment is bounded, then every lower moment
converges to the corresponding moment of the exact gap distribution.
\item A \textbf{boundary correction}: Chan's theorem is stated with the cutoff $s_{n+1}\le x$, whereas the
problem uses $s_n\le x$. Using the current best squarefree-gap bound $g_n\ll s_n^{1/5}\log s_n$, I show
that these two cutoffs are asymptotically equivalent for every moment exponent $<5$.
\end{enumerate}

\subsection*{4) ATTACK PLAN (ROUND-2)}

After Round-1, the exact remaining gap is not the existence of finite-pattern statistics --- those can be
attacked directly by classical correlation theorems for $\mu^2$ --- but the passage from \emph{fixed}
gap lengths to \emph{unbounded} moments.

So the plan is:

\begin{enumerate}
\item Prove that for every fixed $m$, the density of gaps of length exactly $m$ exists.
\item Package those densities into a countable distribution $(p_m)_{m\ge 1}$.
\item Show that any bounded higher moment controls the tail and therefore forces convergence of all
smaller moments.
\item Use the Round-1 first moment to get a new proof for all $0\le \alpha<1$.
\item Combine the transfer lemma with Chan's theorem (and the boundary correction) to identify the
constants for all $0\le \alpha<3.75$.
\end{enumerate}

\subsection*{5) WORK (ROUND-2)}

Let
\[
q(n):=\mu^2(n)\in \{0,1\},
\qquad
g_k:=s_{k+1}-s_k.
\]

\paragraph{\textbf{External input (Mirsky pattern theorem).}}
For every finite set $A\subset \mathbb Z_{\ge 0}$ there exists a constant $c_A\ge 0$ such that
\[
\sum_{n\le x}\ \prod_{a\in A} q(n+a) = c_A x + o(x)
\qquad (x\to\infty).
\]
I use this as a black box.

\paragraph{\textbf{Theorem 145.1 (exact gap frequencies exist).}}
For each fixed integer $m\ge 1$, the limit
\[
p_m:=
\lim_{x\to\infty}
\frac1x\#\{k:\ s_k\le x,\ g_k=m\}
\]
exists.

\paragraph{\textit{Proof.}}
Define the exact-gap indicator
\[
I_m(n):=q(n)\,q(n+m)\prod_{j=1}^{m-1}(1-q(n+j)).
\]
Then $I_m(n)=1$ if and only if $n$ is squarefree, $n+m$ is squarefree, and every integer
between them is non-squarefree. In other words, $I_m(n)=1$ if and only if $n=s_k$ and
$g_k=m$ for some $k$.

Therefore
\[
\#\{k:\ s_k\le x,\ g_k=m\}=\sum_{n\le x} I_m(n).
\]
Now expand the product:
\[
I_m(n)=
q(n)q(n+m)\sum_{S\subseteq \{1,\dots,m-1\}} (-1)^{|S|}\prod_{j\in S} q(n+j).
\]
Hence $I_m(n)$ is a finite linear combination of terms of the form
\[
\prod_{a\in A} q(n+a)
\]
with $A\subseteq \{0,1,\dots,m\}$ finite. By Mirsky's theorem, the average of each such term
over $n\le x$ has a limit. Therefore
\[
\frac1x\sum_{n\le x} I_m(n)
\]
has a limit as $x\to\infty$. This limit is exactly $p_m$. \hfill $\square$

\paragraph{\textbf{Corollary 145.2 (finite-support test functions).}}
If $f:\mathbb N\to \mathbb R$ has finite support, then
\[
\frac1x\sum_{s_k\le x} f(g_k)\to \sum_{m\ge 1} f(m)p_m.
\]

\paragraph{\textit{Proof.}}
Write $f=\sum_{m\ge 1} f(m)\mathbf 1_{\{m\}}$; the sum is finite. Then apply Theorem 145.1 termwise.
\hfill $\square$

\paragraph{\textbf{Lemma 145.3 (moment transfer from a higher moment).}}
Fix $\alpha\ge 0$. Assume there exists $\beta>\alpha$ such that
\[
\sup_{x\ge 1} M_\beta(x)<\infty,
\qquad
M_\beta(x):=\frac1x\sum_{s_k\le x} g_k^\beta.
\]
Then the limit
\[
\lim_{x\to\infty} M_\alpha(x)
\]
exists, and equals
\[
\sum_{m\ge 1} m^\alpha p_m.
\]

\paragraph{\textit{Proof.}}
For each $x$, write
\[
M_\alpha(x)=\sum_{m\ge 1} m^\alpha \nu_x(m),
\qquad
\nu_x(m):=\frac1x\#\{k:\ s_k\le x,\ g_k=m\}.
\]
Fix $Y\ge 1$. By Theorem 145.1,
\[
\sum_{m\le Y} m^\alpha \nu_x(m)\to \sum_{m\le Y} m^\alpha p_m
\qquad (x\to\infty).
\]
For the tail, note that for $m>Y$,
\[
m^\alpha \le Y^{\alpha-\beta}m^\beta.
\]
Hence
\[
\sum_{m>Y} m^\alpha \nu_x(m)
\le
Y^{\alpha-\beta}\sum_{m>Y} m^\beta \nu_x(m)
\le
Y^{\alpha-\beta} M_\beta(x).
\]
Taking $\limsup$ and using the assumed boundedness of $M_\beta(x)$ gives
\[
\limsup_{x\to\infty}\sum_{m>Y} m^\alpha \nu_x(m)\ll Y^{\alpha-\beta}\to 0.
\]
Thus the tails are uniformly negligible, and
\[
M_\alpha(x)-\sum_{m\le Y} m^\alpha \nu_x(m)\to 0
\]
uniformly in $x$ as $Y\to\infty$.

It follows that the partial sums
\[
S_Y:=\sum_{m\le Y} m^\alpha p_m
\]
form a bounded increasing sequence (indeed $S_Y\le \liminf_x M_\alpha(x)\le \sup_x M_\beta(x)$),
so $S_Y\to S$ for some finite $S$. Then
\[
\limsup_{x\to\infty}|M_\alpha(x)-S|
\le
\limsup_{x\to\infty}\left|M_\alpha(x)-\sum_{m\le Y} m^\alpha \nu_x(m)\right|
+
\left|\sum_{m\le Y} m^\alpha p_m-S\right|.
\]
First let $x\to\infty$, then $Y\to\infty$. Both terms go to $0$, so $M_\alpha(x)\to S$.
By definition, $S=\sum_{m\ge 1} m^\alpha p_m$. \hfill $\square$

\paragraph{\textbf{Corollary 145.4 (new unconditional interval $0\le \alpha<1$).}}
For every real $\alpha$ with $0\le \alpha<1$,
\[
\lim_{x\to\infty} M_\alpha(x)
\]
exists, and
\[
\lim_{x\to\infty} M_\alpha(x)=\sum_{m\ge 1} m^\alpha p_m.
\]

\paragraph{\textit{Proof.}}
For $0\le \alpha<1$, take $\beta=1$. Round-1 proved $M_1(x)\to 1$, so in particular
$\sup_x M_1(x)<\infty$. Now apply Lemma 145.3. \hfill $\square$

\medskip

This is already a strict advance beyond Round-1: it upgrades the two isolated cases $\alpha=0,1$
to a full interval $0\le \alpha<1$ by a completely different mechanism.

\paragraph{\textbf{Proposition 145.5 (boundary correction for the cutoff).}}
Define
\[
\widetilde M_\gamma(x):=\frac1x\sum_{s_{k+1}\le x} g_k^\gamma.
\]
Then for every fixed $\gamma<5$,
\[
M_\gamma(x)-\widetilde M_\gamma(x)=o(1).
\]

\paragraph{\textit{Proof.}}
Let $N=N(x)$ be such that
\[
s_N\le x < s_{N+1}.
\]
Then $\widetilde M_\gamma(x)$ is obtained from $M_\gamma(x)$ by omitting exactly the final gap
$g_N=s_{N+1}-s_N$. Hence
\[
0\le M_\gamma(x)-\widetilde M_\gamma(x)\le \frac{g_N^\gamma}{x}.
\]

By the current best upper bound on squarefree gaps, every interval $(y,\,y+11y^{1/5}\log y]$
contains a squarefree integer. Applying this with $y=s_N\le x$ gives
\[
g_N\ll x^{1/5}\log x.
\]
Therefore
\[
0\le M_\gamma(x)-\widetilde M_\gamma(x)
\ll
x^{\gamma/5-1}(\log x)^\gamma,
\]
which tends to $0$ whenever $\gamma<5$. \hfill $\square$

\paragraph{\textbf{Corollary 145.6 (identification of the constants for $0\le \alpha<3.75$).}}
For every real $\alpha$ with $0\le \alpha<3.75$,
\[
\lim_{x\to\infty} M_\alpha(x)
=
\sum_{m\ge 1} m^\alpha p_m.
\]
Equivalently, Chan's constant $B(\alpha)$ is exactly
\[
B(\alpha)=\sum_{m\ge 1} m^\alpha p_m
\qquad (0\le \alpha<3.75).
\]

\paragraph{\textit{Proof.}}
Fix $\alpha<3.75$, and choose $\beta$ with
\[
\alpha<\beta<3.75.
\]
Chan proved that
\[
\widetilde M_\beta(x)=\frac1x\sum_{s_{k+1}\le x} g_k^\beta \to B(\beta),
\]
so $\widetilde M_\beta(x)$ is bounded. By Proposition 145.5, $M_\beta(x)-\widetilde M_\beta(x)=o(1)$,
hence $M_\beta(x)$ is also bounded.

Now Lemma 145.3 applies and yields
\[
M_\alpha(x)\to \sum_{m\ge 1} m^\alpha p_m.
\]
Since Proposition 145.5 also identifies $M_\alpha(x)$ with Chan's cutoff, the limiting constant is
exactly Chan's $B(\alpha)$. \hfill $\square$

\medskip

Thus the unresolved part of Problem \#145 is now completely concentrated in the tail:
the finite-gap statistics are already settled.

\paragraph{\textbf{Sharp obstruction isolated in this round.}}
Define the gap measures
\[
\nu_x(m):=\frac1x\#\{k:\ s_k\le x,\ g_k=m\}.
\]
Theorem 145.1 says that for each fixed $m$, $\nu_x(m)\to p_m$.
Therefore the only remaining issue for general $\alpha$ is the tail quantity
\[
\sum_{m>Y} m^\alpha \nu_x(m)
=
\frac1x\sum_{\substack{s_k\le x\\ g_k>Y}} g_k^\alpha.
\]
If one could prove that for every $\alpha\ge 0$ and every $\varepsilon>0$ there exists $Y$ such that
\[
\limsup_{x\to\infty}
\frac1x\sum_{\substack{s_k\le x\\ g_k>Y}} g_k^\alpha
<\varepsilon,
\]
then the full conjecture would follow immediately from the already-established pointwise gap
frequencies. So the outstanding difficulty is \emph{purely a tail-control problem}.

\subsection*{6) ADVERSARIAL VERIFICATION}

\begin{enumerate}
\item \textbf{Potential issue: fixed-gap frequencies versus the original cutoff.}
This is exact: the quantity
\[
\#\{k:\ s_k\le x,\ g_k=m\}
\]
is literally
\[
\sum_{n\le x} q(n)q(n+m)\prod_{j=1}^{m-1}(1-q(n+j)).
\]
No boundary error appears here.
\item \textbf{Potential issue: Chan's theorem uses $s_{k+1}\le x$, not $s_k\le x$.}
I handled this explicitly in Proposition 145.5 using the current best gap bound
$g_k\ll s_k^{1/5}\log s_k$. This removes a hidden gap in the Round-1 literature summary.
\item \textbf{Potential issue: unjustified exchange of limit and infinite sum.}
No such exchange was made without control. The whole role of Lemma 145.3 is to justify this step
by a quantitative tail estimate coming from a higher bounded moment.
\item \textbf{Potential issue: the interval $0\le \alpha<1$ may already be in the literature.}
That does not matter here. The present proof is a rigorous new derivation from Round-1 data plus
Mirsky's pattern theorem, so it is still strict progress relative to the previous round.
\item \textbf{Potential issue: are the constants $p_m$ summable?}
For each fixed $\alpha<1$, Corollary 145.4 proves that $\sum m^\alpha p_m<\infty$.
So in particular $\sum p_m<\infty$. For larger $\alpha<3.75$, Corollary 145.6 gives the same.
\end{enumerate}

\subsection*{7) FINAL}

\textbf{UNRESOLVED (BUT STRICTLY ADVANCED).}

Round-2 gives a substantially sharper picture than Round-1:

\begin{enumerate}
\item For every fixed gap length $m$, the exact asymptotic frequency $p_m$ exists.
\item For every $0\le \alpha<1$, the problem's limit exists unconditionally and equals
\[
\sum_{m\ge 1} m^\alpha p_m.
\]
\item Combining this framework with Chan's theorem and the current best gap bound shows that for
every $0\le \alpha<3.75$,
\[
\lim_{x\to\infty}\frac1x\sum_{s_n\le x}(s_{n+1}-s_n)^\alpha
=
\sum_{m\ge 1} m^\alpha p_m.
\]
So the limiting constant is now explicitly identified as the $\alpha$-moment of the exact gap distribution.
\item The unresolved part of the Erd\H{o}s problem is now sharply isolated: it is entirely a tail / uniform-integrability
problem for the gap measures $(\nu_x)$ beyond the currently accessible moment range.
\end{enumerate}
